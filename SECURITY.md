# Security policy

Do not open a public issue containing a vulnerability, secret, token, private URL, personal data or production log.

Use GitHub private vulnerability reporting for this repository. If that channel is unavailable, report privately to the repository owner through the existing Libre AI security channel. Never disclose a vulnerability in a public issue.

Secret scanning, push protection, vulnerability alerts and automated security fixes are enabled on the canonical repository. GitHub contains public source and CI metadata only; never place production secrets, personal data or private runtime logs in the forge.

The bootstrap repository is pre-production. This does not reduce the severity of supply-chain, authorization, data-loss or secret-exposure reports.
