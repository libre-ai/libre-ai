# Security policy

Do not open a public issue containing a vulnerability, secret, token, private URL, personal data or production log.

Until the canonical Forgejo security contact is provisioned, report privately to the repository owner through the existing Libre AI security channel. The final contact and response SLA must be configured before the repository becomes public.

The bootstrap repository is pre-production. This does not reduce the severity of supply-chain, authorization, data-loss or secret-exposure reports.
