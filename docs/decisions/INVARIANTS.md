# Registre des invariants

Liste exhaustive des invariants de doctrine de l'écosystème Libre AI. **Ce qui ne figure pas ici n'est pas doctrine.** Chaque entrée porte la source de son arbitrage propriétaire et sa date. Toute modification passe par une pull request portant la trace de l'arbitrage ; toute doctrine sans entrée dans ce registre est nulle (ADR-0008).
