# Practices

- **Path:** `apps/practices`
- **Purpose:** train responsible decisions in professional AI situations.
- **Runtime:** Bun/React/PWA with governed local content.
- **Owns:** activities, learning sessions, private progress and anonymous aggregates.
- **Does not own:** HR scoring or automatic publication of generated content.
- **Rust candidate:** deterministic scoring/content validation only if retained invariants justify it.
- **Critical gates:** human content review, sourced claims, no nominative leaderboard, export, RLS, offline and accessibility.
