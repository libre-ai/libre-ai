# Reviews — preuves immuables, non normatives

Ce dossier contient l'évidence des passes de revue (verdicts, candidats, rapports hashés). **Rien ici n'est normatif** : ces documents prouvent ce qui a été examiné et décidé à une date donnée ; ils ne définissent jamais l'état courant ni la doctrine (carte d'autorité : `docs/README.md`). Un agent qui cite un fichier de ce dossier le cite comme preuve datée, pas comme autorité.
